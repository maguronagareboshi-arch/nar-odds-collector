# nar-odds-collector

地方競馬公式サイト(keiba.go.jp)の当日オッズ(枠連複・枠連単・馬連・馬単・ワイド・3連複・3連単)を
発走前後の短い窓だけ取得し、Supabase の表に保存する GitHub Actions ジョブです。標準ライブラリのみ。

- 2 分おきのループ(loop.py)。1 リクエスト 1 秒、対象は発走 40 分前〜8 分後のレースだけ。最終オッズが出たレースは以後取りません。
- 単勝・複勝(odds_tanfuku.py)と 7 券種(odds_full.py)の 2 本。オッズにはページに書かれた時刻(「HH:MM 現在」)を添えます。
- 発走時刻の当日更新(post_time_refresh.py・5 周に 1 回)。発走時刻はその日にずれることがあり、公式の一覧が正です。
- 当日の券種別「総票数」(sales_rakuten.py・3 周に 1 回・1 回 1 場)。締切前には出ないので、出たぶんだけ後追いで読みます。
  取得元の robots.txt が Crawl-Delay: 60 を出しているため、続けては取らず、同じ場は 30 分に 1 度までにしています。
- 当日の確定結果と払戻(results_today.py・毎周)。公式の日次 ZIP(DataDownload)を読み、結果の入ったレースだけを書きます。公式 ZIP には発走の 6〜9 分後に載ります。
- 公式の数値をそのまま写します(人気は公式の同順位を保持)。
- 接続先は Secrets(`SUPABASE_URL` / `SUPABASE_SERVICE_KEY`)で与えます。
